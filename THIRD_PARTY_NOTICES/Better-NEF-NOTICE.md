## What was modified

Modified by ii8we, version dated **15 October 2026**, starting from NotEnoughFakepixel 1.2.4-beta.
The main changes are:

- the mod is shown as "better-nef" (the internal mod id `notenoughfakepixel` is unchanged, so existing
  configs keep working);
- new config search, "Events" category, casual wording for option names and descriptions;
- dungeon map: rotating map by default, hold-to-show full map with player names, border colour;
- Abiphone panel with player heads, pages and favourites; configurable chat history length;
- chat copy mode (hold Shift), protection star drawn on top of items, Leaping Sword cobweb fix;
- `/pb` shows only the fastest full run, Spirit Leap colours, S+ message spam fix;
- removed: Boss Highlight, the duplicate Floor & S+ tip, Secret Finder and room detection.
