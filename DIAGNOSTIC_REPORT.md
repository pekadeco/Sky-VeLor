# Lunaria diagnostics

Use the following client-side routes when collecting support evidence:

- `/lunaria selftest` — local hook and feature status.
- `/lunaria dungeon debug` — observed dungeon/sidebar/tab/chat score evidence.
- `/lunaria itemdebug` — held-item animation/debug values.
- `/lunaria lockdebug` — Item Lock & Swap state.
- `/lunaria chatdebug` — local Chat QoL geometry/state.
- `/lunaria layoutdebug` — settings-layout bounds overlay.

The older aliases remain accepted for compatibility. Diagnostic output is local client output; review it before sharing because it may include server-visible text you supplied to the client.
